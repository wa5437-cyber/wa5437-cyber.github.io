개인정보처리방침

최종 수정일: 2026년 7월 28일

이 개인정보처리방침은 macOS 앱 NORA(이하 "앱")에 적용됩니다. NORA는 커버곡 녹음과 보컬 믹싱을 위한 도구이며, 아래 원칙에 따라 개인정보를 처리합니다.

수집하는 정보

NORA는 어떠한 개인정보나 사용 데이터도 수집, 저장, 전송하지 않습니다. 회원가입이나 로그인 기능이 없으며, 서버와 통신하지 않고, 분석(Analytics) 도구나 광고 SDK를 포함하지 않습니다.

기기 권한 사용

  • 마이크 접근 — 보컬 녹음 기능을 위해서만 사용되며, 녹음된 오디오는 사용자의 기기 안에만 저장됩니다. 외부로 전송되지 않습니다.
  • 파일 접근 — 사용자가 직접 선택한 MR 파일을 불러오거나, 완성된 결과물(WAV/MP3)을 사용자가 지정한 위치에 저장하기 위한 용도로만 사용됩니다.

데이터 처리 방식

녹음, 믹싱, 마스터링을 포함한 모든 오디오 처리는 사용자의 Mac 안에서만 이루어집니다. 인터넷 연결이 필요하지 않으며, 어떤 형태의 사용자 콘텐츠도 Apple을 포함한 어떤 제3자에게도 전송되지 않습니다.

제3자 공유

NORA는 제3자와 공유하는 개인정보가 없습니다. 광고나 제휴 링크도 포함하지 않습니다.

변경 사항

이 방침이 변경될 경우 이 페이지에 업데이트된 내용을 반영합니다.

NORA 사용 순서

Quick Start

① 장비 설정(마이크 선택) → ② MR 업로드(키/BPM 자동 분석) → ③ 녹음 → ④ 보컬 스타일 & 믹싱 → ⑤ 마스터링 & 내보내기(WAV/MP3)

자주 묻는 질문

녹음할 때 제 목소리가 안 들려요.

실시간 모니터링은 헤드폰이 연결되어 있을 때만 자동으로 활성화됩니다. 헤드폰 연결 상태와 시스템 환경설정의 마이크 권한(개인정보 보호 및 보안 → 마이크)이 NORA에 대해 허용되어 있는지 확인해주세요.

MR 파일의 키/BPM이 다르게 인식돼요.

자동 분석은 참고용입니다. 곡의 구조나 음질에 따라 오차가 있을 수 있으니, 필요하면 수동으로 확인 후 녹음을 진행해주세요.

내보내기한 파일을 찾을 수 없어요.

내보내기 시 저장 위치를 직접 선택하도록 되어 있습니다. 저장 다이얼로그에서 선택한 폴더(기본값은 보통 '다운로드' 폴더)를 확인해주세요.

앱이 실행되지 않거나 강제 종료돼요.

macOS 버전이 12.0 이상인지 확인해주세요. 문제가 계속되면 아래 이메일로 macOS 버전과 증상을 함께 보내주시면 빠르게 도와드리겠습니다.
