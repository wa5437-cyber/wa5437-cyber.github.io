NORA

사용법 · 지원

반주를 올리면 키와 템포를 자동으로 잡고, 부르고, 틀린 곳만 다시 녹음하고, 보컬 스타일을 골라 마스터링까지 합니다. 오디오 장비를 몰라도 커버곡 한 곡을 끝낼 수 있게 만든 맥 앱입니다. 아래는 처음 여는 사람의 순서입니다.

사용법

다섯 단계면 한 곡이 끝납니다. 처음이라면 헤드폰을 꼭 끼세요 — 스피커로 들으면서 녹음하면 반주가 마이크로 다시 들어갑니다.

1장치 진단 — 마이크를 고르고 음량을 맞춘다

마이크를 고르고 한 소절 불러 음량을 맞춥니다. 지연 시간(레이턴시)과 헤드폰 연결은 NORA 가 대신 확인해 알려줍니다.

헤드폰을 빼면 실시간 모니터링이 자동으로 꺼집니다. 하울링이 나기 전에 앱이 먼저 끕니다.

2MR 업로드 — 키와 템포를 자동으로 잡는다

MP3·WAV·M4A 를 올리면 키와 템포(BPM)를 분석합니다. 분석은 참고용이니 다르다 싶으면 직접 고쳐도 됩니다.

3녹음 — 틀린 구간만 다시 부른다

반주에 맞춰 부릅니다. 틀린 곳이 있으면 파형에서 그 구간만 끌어 다시 녹음(펀치인)하면 앞뒤가 자연스럽게 이어집니다. 처음부터 다시 부를 필요가 없습니다.

모니터링용 리버브는 녹음 파일에 들어가지 않습니다. 부를 때는 울림을 듣고, 저장되는 소리는 항상 깨끗합니다.

4보컬 스타일 — 버튼 하나로 음색을 바꾼다

샤방하게·단단하게·감성적으로·시원하게·자연스럽게 중에서 고르면 그에 맞춰 믹싱됩니다. 음정 보정도 함께 들어갑니다 — 얼마나 걸지는 조절할 수 있습니다.

5마스터링과 내보내기

마스터링으로 라우드니스를 시중 음원 수준에 맞추고 MP3 또는 WAV 로 저장합니다. 저장 위치는 직접 고릅니다.

내보낸 파일이 안 보이면 저장 대화상자에서 고른 폴더를 확인해 주세요. 기본값은 보통 '다운로드' 입니다.

＋그밖에 알아 두면 좋은 것

  • 모든 처리는 내 Mac 안에서 이뤄집니다. 계정도, 목소리 업로드도 없습니다.
  • 키·템포 분석은 참고값입니다. 곡의 구조나 음질에 따라 어긋날 수 있어 직접 확인하는 편이 안전합니다.
  • macOS 12.0 이상에서 동작합니다.

자주 묻는 질문

여기서 답을 못 찾으시면 아래 메일로 알려주세요. macOS 버전과 증상을 함께 적어 주시면 빠릅니다.

녹음할 때 제 목소리가 안 들려요.

실시간 모니터링은 헤드폰이 연결되어 있을 때만 켜집니다. 헤드폰 연결과 시스템 설정의 마이크 입력 장치를 확인해 주세요.

MR 파일의 키·BPM 이 다르게 인식돼요.

자동 분석은 참고용입니다. 곡 구조나 음질에 따라 오차가 있을 수 있으니, 필요하면 값을 직접 확인하고 고친 뒤 녹음하세요.

내보내기한 파일을 찾을 수 없어요.

내보낼 때 저장 위치를 직접 고르게 되어 있습니다. 저장 대화상자에서 선택한 폴더(기본값은 보통 '다운로드')를 확인해 주세요.

앱이 실행되지 않거나 강제 종료돼요.

macOS 버전이 12.0 이상인지 확인해 주세요. 그래도 계속되면 macOS 버전과 증상을 아래 메일로 보내주시면 빠르게 도와드리겠습니다.

녹음에 반주 소리가 같이 들어갑니다.

스피커로 반주를 들으면서 녹음하면 그 소리가 마이크로 다시 들어갑니다. 헤드폰을 끼고 녹음해 주세요.

개인정보처리방침

최종 수정일: 2026년 7월 28일

적용 범위

이 방침은 macOS 앱 NORA 에 적용됩니다. ML Music Studio 의 다른 앱과 웹사이트 도구에 대한 방침은 사이트의 전체 개인정보처리방침에 있습니다.

수집하는 정보

NORA 는 어떠한 개인정보나 사용 데이터도 수집·저장·전송하지 않습니다. 회원가입이나 로그인 기능이 없고, 분석 도구나 광고 SDK 도 쓰지 않습니다.

기기 권한

  • 마이크 — 보컬 녹음에만 씁니다. 녹음된 소리는 사용자의 Mac 안에만 저장됩니다.
  • 파일 — 사용자가 직접 고른 MR 파일을 읽고, 완성한 결과물을 사용자가 지정한 위치에 저장할 때만 씁니다.

데이터 처리 방식

녹음·믹싱·마스터링을 포함한 모든 오디오 처리는 사용자의 Mac 안에서만 이뤄집니다. 인터넷 연결이 필요하지 않으며, 목소리가 외부로 나가지 않습니다.

제3자 공유

제3자와 공유하는 개인정보가 없습니다. 광고나 제휴 링크도 없습니다.

변경 사항

방침이 바뀌면 이 페이지에 반영하고 위의 최종 수정일을 갱신합니다.
