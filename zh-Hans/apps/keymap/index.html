DAW 快捷键 — KeyMap

学习、转换、练熟 DAW 热键

搜索、转换并练习 Pro Tools、Logic、Ableton、FL Studio、Studio One 和 Cubase 的快捷键。支持 Mac 与 Windows 按键。Pro 一次买断，终身使用，无订阅。

App Store

截图

不用再到处翻 PDF 速查表。KeyMap 把六大主流 DAW（数字音频工作站）的全部键盘快捷键集中在一处，一搜即得 — Pro Tools、Logic Pro、Ableton Live、FL Studio、Studio One 和 Cubase。

搜索
• 收录数千条快捷键，可按名称、操作和按键检索。输入“分割”“bounce”，或用你自己的语言输入，立刻出结果 — 支持中文、英语、韩语、日语、德语、葡萄牙语、西班牙语和法语搜索。
• 显示绑定到一条命令的所有按键，而不只是主要的那个。例如 Pro Tools 的录音，会同时列出 ⌘Space、F12 和小键盘 3。
• 可按类别或按 DAW 浏览。

跨 DAW 转换
• 在一个 DAW 里会用的快捷键，换到另一个 DAW 里想不起来？KeyMap 把同一个操作对应到全部六个 DAW。无论是从 Logic 转到 Pro Tools，还是只想知道 Ableton 怎么做，对应的快捷键点一下就能看到。

练出肌肉记忆
• 专为快捷键设计的间隔重复训练。闪卡模式先让你回想，再自行核对；选择题模式则用真实、容易混淆的错误按键来考你。
• 按类别划分的练习集、每日连续打卡，以及把你反复答错的内容重新翻出来的复习调度。
