AET Quiz

옴의 법칙부터 RT60까지, 오디오 엔지니어링 계산을 랜덤 문제로 반복 연습하는 퀴즈 앱입니다.

  • 전기·딜레이·음향·템포&피치 4개 카테고리와 혼합 문제
  • 5·10·15·20문제 중 선택, 매번 새 문제를 랜덤 출제
  • 정답을 고르면 공식과 함께 해설이 바로 표시
  • 라운드 진행·정답 수·정답률을 실시간으로 확인
  • 로그인·광고·추적 없이 인터넷 연결 없이도 사용
App Store무료 · 광고·로그인 없음

랜덤 계산 문제

기온에 따른 음속, 주기, 재생 속도와 피치처럼 전기·딜레이·음향·템포 분야의 계산 문제가 매번 새로 출제됩니다.

정답마다 공식 해설

답을 고르면 정답이 표시되고, 계산에 쓴 공식과 풀이가 바로 나옵니다.

라운드 결과와 정답률

라운드가 끝나면 맞힌 문제 수와 정답률을 보여 주고, 바로 다시 도전할 수 있습니다.

사용법

  1. 카테고리를 고릅니다
    전기·딜레이·음향·템포&피치 또는 혼합을 선택합니다.
  2. 문제 수를 정합니다
    5·10·15·20문제 중 하나를 고르고 시작합니다.
  3. 문제를 풀고 해설을 봅니다
    답을 고를 때마다 공식 해설이 나옵니다.
  4. 결과를 확인하고 다시 풉니다
    정답률을 확인한 뒤 새 문제로 다시 도전합니다.
