TempoScope

마이크로 들려주면 템포와 키를 실시간으로 찾아주고, 메트로놈과 딜레이·리버브 타임 계산까지 한 앱에서 쓰는 템포 도구입니다.

  • 마이크로 템포(BPM)와 키를 실시간 감지 (키는 참고용)
  • 찾은 BPM 에 맞는 딜레이·리버브 타임을 ms 로 계산
  • 30~300 BPM 메트로놈, 마디 맵, 드럼 스타일 프리셋 59종
  • 음원 파일 분석: 템포·키·코드 진행 (코드는 참고용)
  • 클릭에 맞춰 녹음해 MIDI 로 변환 (참고용), 분석은 전부 기기 안에서
App Store무료로 시작 · Pro 는 평생 이용권(한 번 구매, 구독 아님)

음원 파일을 한 번에 분석

음원 파일을 넣으면 템포·키·코드 진행을 한 번에 뽑습니다. 코드 분석은 참고용이며, 곡 전체 분석은 Pro 이고 무료는 앞 60초까지입니다.

녹음해서 MIDI 로

클릭에 맞춰 연주를 녹음하면 음을 받아 적어 피아노롤로 보여 줍니다. 참고용이며, 녹음하고 결과 보기는 무료, MIDI 내보내기는 Pro 입니다.

메트로놈은 전부 무료

30~300 BPM, 여러 박자, 박 나누기와 6가지 음색을 쓸 수 있고 백그라운드에서도 계속 울립니다.

사용법

  1. 마이크로 들려줍니다
    라이브 탭에서 음악을 들려주면 템포와 키가 표시되고 딜레이·리버브 타임이 바로 계산됩니다.
  2. 파일로 분석합니다
    파일 분석 탭에서 음원 파일을 열면 템포·키·코드 진행을 볼 수 있습니다.
  3. 메트로놈으로 이어 씁니다
    찾은 템포로 메트로놈을 켜고 연주합니다.
  4. 연주를 녹음해 MIDI 로 바꿉니다
    클릭에 맞춰 한 악기씩 녹음하면 피아노롤로 확인할 수 있습니다.
  • iPhone · iPad
  • 메트로놈은 전부 무료
  • 인터넷·계정·광고 없음 (분석은 기기 안에서)
  • 정답을 아는 13곡 중 템포 13곡 일치 (표본 작음, 키·코드는 참고용)
