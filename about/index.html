이효섭

소개

믹싱·마스터링·녹음을 하는 사운드 엔지니어입니다. 서울 용산의 작업실에서 ML Music Studio를 운영합니다.

무대·공연 음향 현장에서 일한 경험을 바탕으로, 현장에서 실제로 쓰게 되는 계산·측정·학습 도구를 앱과 웹 도구로 만들고 있습니다.

Moon Studio 팀 페이지

  • 2009년부터 작업을 기록해 두었습니다.
  • 기록된 작업 111건
  • 그중 마스터링 66건 · 믹싱 49건 · 녹음 30건 (한 작업에 여러 역할이 겹칩니다)

만든 것

앱

무대음향 시험 대비, SPL·RTA 측정, 귀 훈련, DAW 단축키, 악보 변환까지. 현장에서 쓰려고 만든 앱입니다.

웹 도구

RTA 분석기, 신호 발생기, 귀 훈련, 딜레이·음향·전기·템포 계산기를 브라우저에서 바로 쓸 수 있습니다.

가이드

딜레이 타워 정렬, 임피던스, RTA 해석, 자격증 대비 같은 실무 글입니다.
