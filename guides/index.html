GUIDES

현장에서 바로 쓰는 사운드 실무 가이드

딜레이 타임 계산, 스피커 임피던스, RTA 해석, 자격증 대비까지. 공식과 실제 숫자를 넣은 계산 예시로 정리했습니다. 각 글은 관련 무료 웹 도구·앱과 연결됩니다.

도구 가이드

딜레이 타워, 거리로 딜레이 타임 계산하는 법

음속과 온도 보정 공식, 하스 효과를 고려한 추가 지연, 여러 존을 정렬하는 실전 순서.

스피커 임피던스 — 직렬·병렬 연결과 앰프 매칭

공칭 임피던스의 의미, 병렬·직렬 계산, 앰프가 견디는 최소 부하와 2Ω의 위험.

31밴드 RTA 읽는 법 — 룸 모드와 하울링 포인트

핑크노이즈 기준선, 저역 피크·딥으로 룸 모드 읽기, 피드백 직전 밴드 잡아내기.

데시벨 공식과 단위 총정리 — 10log·20log, dBu·dBV·dBFS·dB SPL

파워 10log·진폭 20log가 갈리는 이유, 배수 환산표, 단위별 기준값, dB 합산 계산.

31밴드 그래픽 EQ 표준 주파수 — 1/3옥타브 중심주파수 표와 계산

ISO 266·IEC 61260 표준 중심주파수 31개 표, ×1.26 계산식, 공칭값 vs 정확값, 슬라이더 대역폭.

RT60·잔향시간 이해와 계산

−60 dB 감쇠 시간의 정의, 사빈 공식 계산, 재료별 흡음 계수, 측정법, 용도별 목표값과 명료도(STI).

오디오를 위한 옴의 법칙 — 전압·전류·전력과 스피커 부하

V=IR과 전력 공식을 앰프·스피커에 적용. 임피던스와 전류, 70V/100V 라인, 케이블 손실.

주파수와 파장 계산 — 저역 룸모드·베이스트랩·마이크 위치

주파수↔파장 공식, 옥타브 관계, 베이스 트랩 두께·룸 모드·마이크 3:1 룰이 파장과 맞닿는 지점.

위상 간섭과 콤필터 — 시간차가 만드는 빗살 모양 주파수 특성

시간차 T가 만드는 골 1/(2T)와 간격 1/T, 마이크 3:1 법칙, 극성 반전과 위상 차이, 벽 사이 정상파 계산.

마이크 지향성 패턴 이해 — 카디오이드·양지향성·무지향

극좌표 그래프 읽는 법, 근접효과, 슈퍼/하이퍼카디오이드 차이와 실전(보컬·라이브·앙상블) 선택 가이드.

SPL과 역제곱 법칙 — 거리별 음압 감쇠 계산

거리 2배당 −6dB 공식과 계산 예시, 라인 어레이가 예외인 이유, 딜레이 스피커 SPL 맞추기.

XLR·TRS·TS 커넥터와 밸런스드 신호 — 왜 노이즈에 강한가

XLR·TRS·TS 핀 구조, 핫·콜드 차동 전송이 노이즈를 상쇄하는 원리와 숫자 예시, DI 박스와 실전 연결 규칙.

EQ 종류와 Q값 — 그래픽·파라메트릭·셸빙, 대역폭 계산

EQ 4종의 차이, Q=중심 주파수÷대역폭 계산, 하울링·음색·저역 정리에서 Q를 고르는 기준.

라인 어레이 기초 — 커버리지·박스 각도·거리 감쇠

스피커를 세로로 잇는 이유, 박스 사이 각도로 객석을 나누는 법, 근거리 −3dB 감쇠와 점음원 전환 거리 계산.

콘덴서 vs 다이나믹 마이크 — 원리 차이와 용도별 선택

전자기 유도와 정전용량 변화라는 발전 원리 차이, 팬텀파워가 필요한 이유, 감도·최대 SPL 차이와 상황별 선택 가이드.

메트로놈 연습 가이드 — BPM 정하기·가속 연습

BPM과 한 박의 길이, 템포 용어, 목표 템포의 60~70%에서 시작하는 단계별 연습, 박자표·분할·가속 연습 설정.

믹싱·측정

LUFS·라우드니스 미터 읽는 법

Integrated·Short-term·Momentary의 차이, True Peak·LRA, 스트리밍 플랫폼별 목표값과 정규화 동작.

BPM으로 딜레이·리버브 타임 계산하기

1박의 밀리초 구하는 공식, 음표별 딜레이 타임 표, 리버브 프리딜레이·트레몰로 속도까지 템포에 맞추기.

Reverb·Delay·Chorus·Flanger·Phaser 차이

지연 시간·피드백·모듈레이션 세 변수로 시간 기반 이펙트를 구분하고 실전에서 언제 쓰는지.

컴프레서 파라미터 제대로 이해하기

Threshold·Ratio·Attack·Release가 소리에 미치는 영향을 수치 예시로, 게이트·더킹과의 차이와 악기별 시작값까지.

핑크노이즈로 EQ 귀 훈련하는 법

핑크노이즈가 EQ 훈련에 쓰이는 이유, 밴드 부스트를 귀로 구분하는 단계별 훈련, 헷갈리는 주파수 쌍.

게인 스테이징 기본 — 헤드룸과 노이즈 플로어 사이

단계별(프리앰프·컨버터·트랙·마스터) 적정 레벨, dBFS·dBu 관계, 플러그인 체인에서의 게인 스테이징.

믹싱 작업 시간과 휴식 — 타이머로 리듬 만들기

작업·휴식 리듬 출발점, 휴식 후 듣는 순서, 세 시간 세션 시간표, 합주실·녹음실 대관 시간 관리.

DAW·워크플로우

DAW 단축키, 왜 다 다르고 어떻게 외워야 할까

DAW마다 단축키 철학이 다른 이유, 공통 단축키와 DAW별 단축키 구분, 동작 단위로 외우는 법.

Pro Tools에서 Logic으로 — 용어·워크플로우 대응표

세션↔프로젝트, 클립게인↔오토메이션, 엘라스틱 오디오↔플렉스 타임 등 용어·편집모드·단축키 대응.

Ableton Live·FL Studio — 루프 기반 워크플로우 이해하기

세션 뷰·패턴 기반 작업방식과 선형 편집의 차이, 클립·패턴·플레이리스트 대응표, Warp로 루프를 템포에 맞추는 계산법.

자격증·학습 가이드

무대예술전문인(음향) 3급 시험범위 — 기출 17회분으로 본 주제별 출제 비중

3급 필기 17회분 기출 992문항의 과목·주제별 출제 비중과 공부 우선순위.

무대예술전문인(음향) 3급 필기 배점·과락 계산 — 몇 문제면 합격인가

75문항 배점표, 합계 60점과 영역별 과락선을 문항 수로 환산, 사례 계산과 배점 기준 공부 우선순위.

무대예술전문인(음향) 3급 필기 — 과목별 순서와 3주 플랜

음향·법규·일반의 비중과 난이도, 과락을 피하는 공부 순서, 주차별 학습 계획.
