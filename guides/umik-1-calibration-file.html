UMIK-1 보정 파일 사용법

믹싱·측정 · 약 5분

완전히 평평한 마이크는 없습니다. 측정용 USB 마이크 miniDSP UMIK-1은 개체마다 측정한 주파수별 편차를 보정 파일로 제공하고, 측정 소프트웨어가 이 값을 반영해 마이크가 만든 오차를 걷어 냅니다. 그래프에 남는 것이 스피커와 방의 특성이 되도록 하는 장치입니다.

보정 파일이 하는 일

파일에는 주파수별 편차(dB)가 줄줄이 적혀 있습니다. 예를 들어 8kHz가 +2dB라면 그 마이크가 8kHz를 2dB 크게 듣는다는 뜻이고, 소프트웨어가 그만큼을 빼서 보여 줍니다. 2dB는 진폭으로 약 1.26배 차이로, EQ 판단에는 충분히 의미 있는 크기입니다.

파일 받기

  • 마이크 본체에 적힌 7자리 시리얼 번호를 확인합니다.
  • miniDSP 홈페이지의 UMIK-1 보정 파일 페이지에 번호를 입력합니다.
  • 파일이 두 개 내려옵니다. 시리얼 번호 이름의 txt가 기본(0°) 파일이고 다른 하나가 90° 파일입니다.

파일은 마이크마다 다릅니다. 다른 사람의 파일을 쓰면 맞지 않으니 내 번호로 받은 파일을 따로 보관하세요.

0° 파일과 90° 파일

파일마이크 방향쓰는 경우
0°끝이 소리 쪽(스피커)을 향함스피커 한 대·스테레오 페어 측정
90°마이크를 세워 소리가 옆에서 들어옴서라운드처럼 여러 방향에서 소리가 오는 환경

소프트웨어에 적용하기

REW 같은 측정 프로그램에는 보정 파일을 불러오는 항목이 있습니다. 입력 장치로 UMIK-1을 고르고 파일을 지정하세요. 파일을 바꿨다면 이전 측정값은 보정이 달랐던 것이므로 다시 측정합니다.

감도로 SPL 환산하기

파일 상단에는 마이크 감도(dBFS/Pa) 정보도 들어 있습니다. 1Pa가 94dB SPL이라는 기준으로 소프트웨어가 디지털 레벨을 음압으로 바꿉니다.

SPL = 94 + (입력 dBFS − 감도 dBFS/Pa)
예시 (감도 −20 dBFS/Pa라고 가정) 입력 −20 dBFS → 94dB SPL, −26 dBFS → 88dB SPL, −40 dBFS → 74dB SPL. 실제 감도는 내 파일에서 확인하세요.

입력 게인을 바꾸면 이 대응이 틀어지므로, SPL로 읽을 때는 보정 때와 같은 설정을 유지합니다. 보정 파일은 마이크의 주파수 특성만 바로잡으며 방 자체의 문제를 고치지는 않습니다.

자주 묻는 질문

보정을 켜면 소리가 달라지나요?

듣는 소리는 그대로이고 그래프 표시만 바뀝니다. 마이크의 편차가 그래프에서 빠질 뿐입니다.

측정 결과 읽는 법은요?
