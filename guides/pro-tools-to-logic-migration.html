Pro Tools에서 Logic으로 — 용어·워크플로우 대응표

DAW·워크플로우 · 약 7분

Pro Tools에 익숙한 상태로 Logic을 열면 화면은 비슷한데 개념이 자꾸 어긋납니다. 세션이 아니라 프로젝트, 클립 게인이 아니라 게인 오토메이션, 엘라스틱 오디오가 아니라 플렉스 타임. 용어만 바꿔 읽으면 워크플로우 자체는 생각보다 빨리 손에 붙습니다.

편집 모드 차이

Pro Tools는 네 가지 편집 모드(Slip·Shuffle·Spot·Grid)를 전환하며 작업합니다. Logic에는 이 개념이 그대로 없고, 대신 스냅(Snap) 설정 + 드래그 동작으로 비슷한 걸 구현합니다.

Pro Tools 모드Logic에서 비슷한 동작
Slip (자유 이동)Snap = Off
Grid (격자 스냅)Snap = Bar/Beat/Division 등 선택
Shuffle (뒤 리전이 밀려 붙음)정확히 같은 기능 없음. 수동 정렬 또는 Ripple 편집 일부 지원
Spot (숫자 입력으로 위치 지정)리전을 선택 후 Event List / 인스펙터에 위치 직접 입력
Shuffle 모드처럼 "이전 리전 삭제하면 뒤가 자동으로 당겨 붙는" 동작은 Logic에 정확히 없습니다. 대사 편집처럼 Shuffle을 많이 쓰던 작업이라면 이 부분이 가장 적응이 필요합니다.

믹스 구조 차이

  • 채널 스트립 순서 — Pro Tools는 인서트가 위, Logic도 비슷하지만 EQ가 기본으로 눈에 잘 띄는 위치에 있다.
  • 센드 레벨 — Pro Tools 센드는 기본 −inf에서 시작, Logic은 트랙 생성 시 자동으로 0 dB 근처로 열리는 경우가 있어 초반 레벨 서프라이즈에 주의.
  • 버스 채널 수 — Pro Tools는 세션 시작 시 버스 개수를 정해야 함. Logic은 Aux를 필요할 때 그때그때 만들 수 있어 더 유연.
  • 서밍 vs 그룹 — Pro Tools의 VCA/Group과 Logic의 Track Stack(Summing Stack)은 비슷한 목적이지만 조작 방식이 다르다.

흔한 실수

  • Shuffle 모드가 그리워 억지로 흉내낸다. Logic의 워크플로우(마커+드래그)로 새로 익히는 게 빠르다.
  • Flex Time을 Elastic Audio처럼 항상 켜둔다. Logic은 Flex를 켜면 리전마다 분석 오버헤드가 있어 필요한 트랙만 켜는 게 낫다.
  • 버스 수를 Pro Tools 세션처럼 미리 다 만든다. Logic은 필요할 때 만들면 되므로 세션 시작이 오히려 더 가볍다.
  • 플러그인 레이턴시 보상 차이를 모른다. 둘 다 PDC를 지원하지만 세팅 위치가 다르니 새 프로젝트에서 확인.
